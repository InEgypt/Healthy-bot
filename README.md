# Healthy Bot - بوت تغذية تلجرام

بوت تلجرام بسيط لإدارة التغذية وحساب القيم الغذائية اليومية. يدعم حساب السعرات والمغذيات الكبرى، تسجيل الوجبات، وملخص يومي.

## المزايا
- عرض قائمة الأطعمة المتاحة.
- حساب القيم الغذائية حسب الجرام.
- تسجيل الوجبات في قاعدة بيانات محلية.
- ملخص يومي للسعرات والبروتين والكربوهيدرات والدهون.
- اقتراح وجبة متوازنة.

## المتطلبات
- Python 3.10+
- توكن بوت تلجرام

## الإعداد السريع
```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
```

بعدها عدّل ملف `.env` وضع `BOT_TOKEN`.

## التشغيل
```bash
export $(cat .env | xargs)
python src/bot.py
```

## الأوامر داخل البوت
- `/start` بدء الاستخدام.
- `/help` شرح الأوامر.
- `/foods` قائمة الأطعمة.
- `/food <name> <grams>` حساب القيم الغذائية.
- `/log <name> <grams>` تسجيل الوجبة.
- `/summary` ملخص اليوم.
- `/meal` اقتراح وجبة.

## تخصيص قاعدة الأطعمة
يمكنك تعديل الملف `data/foods.json` وإضافة أطعمة جديدة بالقيم لكل 100 جم.

## ملاحظات
- قاعدة البيانات تحفظ في `data/healthy_bot.db`.
- استخدم نفس أسماء الأطعمة الموجودة في `/foods`.
